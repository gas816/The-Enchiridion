# The Enchiridion

这是一个围绕 Epictetus《The Enchiridion（手册）》构建的静态阅读项目。

项目当前以单文件网页的形式提供阅读体验，适合在本地直接打开进行阅读、摘录与反思。页面使用了更接近纸张阅读的视觉设计，并提供了目录导航、阅读进度提示和字号调节等基础功能。

## 项目内容

- 作品：Epictetus《The Enchiridion》
- 形式：单页静态阅读页面
- 当前文件：`epictetus.html`
- 文本来源：Internet Classics Archive
- 译本信息：页面中标注为 Elizabeth Carter 译本

## 项目目标

这个项目的目标不是做复杂的应用，而是提供一个清晰、安静、适合持续阅读斯多葛哲学文本的入口。它适合用于：

- 本地阅读《手册》全文
- 做个人哲学阅读记录
- 作为古典文本展示页的前端练习
- 后续扩展为双语阅读、批注或章节导读项目

## 如何使用

1. 进入项目目录。
2. 直接在浏览器中打开 `epictetus.html`。
3. 通过页面内目录跳转到对应章节。
4. 使用 `A-` 与 `A+` 调整阅读字号。

如果你使用的是 VS Code，也可以安装 Live Server 后打开该页面进行预览，但这个项目本身不依赖构建工具。

## 当前特性

- 单文件部署，结构简单
- 适合阅读的排版与配色
- 固定顶部阅读进度条
- 章节目录导航
- 可调节字号
- 本地即可运行，无需安装依赖
